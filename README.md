# 🏫 Smart School App (स्मार्ट स्कूल)

A bilingual (English + Hindi) school management app built with React + Vite.

## ✨ Features
- Student & Teacher login
- Notice Board
- Attendance tracking
- Fee status
- Performance chart
- Student ID Card
- School Gallery
- Books by Class

## 🚀 Run Locally

```bash
npm install
npm run dev
